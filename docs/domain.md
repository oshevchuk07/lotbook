# Domain glossary

> Заповнюється на етапі 0 і доповнюється по ходу. Один термін = одне значення в коді й документації.

| Термін (EN) | Українською | Визначення |
|---|---|---|
| Item | Товар / позиція | Те, що обліковується: штучна річ або кількісна позиція |
| Lot | Партія | Партія закупівлі з фіксованою повною собівартістю одиниці |
| Stock movement | Рух складу | Незмінний запис зміни кількості (append-only) |
| Ledger | Журнал | Сукупність рухів; джерело істини для залишків |
| Landed cost | Повна собівартість | Ціна одиниці з урахуванням розподілених доставки, мита, знижок |
| Production run | Збірка | Фактичне виробництво виробу з компонентів |
| Channel | Канал продажу | Майданчик продажу з правилами комісій |
| Return | Повернення | Повернення покупцем товару з результатом по кожному рядку |
| Stock take | Інвентаризація | Сесія підрахунку з коригуваннями |
| Reservation | Резерв | Закріплення кількості за замовленням без зміни фізичного залишку |
| Counterparty | Контрагент | Постачальник або клієнт; необов'язкові контакти й нотатки |
| Contact method | Контакт | Телефон, email, Telegram або посилання контрагента |
| Listing | Оголошення | Публікація товару на майданчику з URL, ціною й статусом |
| Command | Команда | Намір змінити стан (RegisterSale); обробляється одним use-case |
| Query | Запит | Читання даних без зміни стану |
| Membership | Членство | Зв'язок користувача з тенантом і роллю |
| Permission | Право | Дозвіл на дію (`sales:create`); ролі це набори прав |
